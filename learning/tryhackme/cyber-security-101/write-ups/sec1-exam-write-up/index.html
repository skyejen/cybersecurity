    SEC1 Exam¶

    Path: Cyber Security 101 > SEC1 Exam

    Date: 20–21/06/2026

    Difficulty: Easy (as per THM, I found it somewhat difficult!)

    Quick Links

    • Exam Details
    • Certificate

    Overview¶

    It's hard to do a write-up on the exam without giving away spoilers for future students, I want to be really careful what I write here, and I will try my best, as I think doing a write-up for me about this experience is essential.

    This write-up is not going to go into details about tools used (again, spoilers), but I will touch upon what was disclosed in the exam brief, how I found it, where I think my knowledge/execution was not quite up to standard, and what aspects I enjoyed more.

    Windows Fundamentals¶

    What this section tested: Perform basic Windows system navigation and security-related tasks.

    I found this scenario very straightforward, maybe even easy. Probably because I've done certain things myself on my own machine already, not just on TryHackMe while learning cybersecurity. It was enjoyable, and I'd be happy to do more of it, especially when there is a real investigation going on, but aside from that, I wouldn't say this was something very captivating. I scored 100/100 in this area and did it fully myself (no Google, no reviewing write-ups, no Claude).

    Linux Fundamentals¶

    What this section tested: Validate core Linux skills including file analysis and permissions.

    This was still not too hard, I do find Linux-related tasks a bit more exciting, probably because I romanticise terminal use quite a lot still. I scored 70/100 and I think I googled a couple of common locations or commands. I'd like to practise more to get more efficient with Linux navigation and just to develop the core and muscle memory of all common locations.

    Network Traffic Fundamentals¶

    What this section tested: Analyse network traffic to identify normal behaviour and potential issues.

    So you see, I love networking. I find it fascinating. Why? Probably because it feels like magic, making communication across the world possible like that. But for some reason I struggled quite a lot in this one. I ended up scoring 100/100 through heavy googling and poking Claude for some more advanced commands (which I thought would be allowed and appropriate use of AI, as I only asked for command chaining and syntax help). I noticed some knowledge gaps in regards to packet info/flags and I know what I need to revisit. I'm not sure if I should target specific rooms and modules for that, or perhaps this would be covered in detail in the blue team path. We will see!

    Could I do this as a job? It's hard to say now because I did feel a bit clueless at first (before I started googling), so I'm trying to imagine how I'd feel if I knew exactly what I was doing (or was fluent in networking "language"). I think so? Although probably not my favourite still.

    Web Pentesting Fundamentals¶

    What this section tested: Identify and assess common web application security weaknesses.

    Two funniest things here. The day before the exam I went through "Burp Suite: The Basics" room and I spent hours and hours on it. I had it penciled to go back to it as when I tried it ages ago I either couldn't get it to work fully or it was a bit too overwhelming for me. But this time I loved every single minute of it (wink wink -> burp-suite-the-basics.md). How unbelievably lucky I was to have done this the day before the exam. I practically walked through the web pentesting scenario. And... I loved it.

    Funniest thing number 2. At the beginning of my cybersecurity journey, for some reason I thought I wouldn't like pentesting. I don't know why, I think maybe this is my fascination and borderline obsession with police and law enforcement, the concept of "serve and protect", read as "blue team". Maybe it's my desire not to be put in a "only QA" box, as pentesting is still quality assurance, just in a different domain to what I have been doing for the last 10 years. But strangest thing, I loved every minute of this scenario. Could it be the direction I need to take? What are the job prospects? The career development? Hm...

    My score was 90/100, by the way. I wish they'd tell me which one I got wrong!

    Security Operations Fundamentals¶

    What this section tested: Perform entry-level blue team tasks such as monitoring and investigation.

    This was an investigative task requiring using multiple tools and event logs. It was interesting to follow the chain of events using the available information, although I did find some questions more challenging than others (had to do a lot of googling on common locations and filtering and reached out to Claude for formatting help when answering). I would defo do it again and would like to get more practice in it to decide if this is something I'd like to pursue. I think I would have enjoyed it a lot more without the countdown as it was adding a lot of stress and I like to check every corner basically, but still managed to get 100/100.

    Bruteforcing and Cracking Fundamentals¶

    What this section tested: Apply basic offensive techniques to assess weak credentials.

    This was very satisfying, I feel like rooms on bruteforcing and cracking were quite extensive in the learning path, that this didn't feel hard at all. It was long enough since I did it for me to require to google some commands and formats, but mostly did everything on the fly. 100/100.

    I did enjoy doing this and I could see myself doing it as a job, but I imagine more in addition to something else rather than full time.

    Malware Analysis Fundamentals¶

    What this section tested: Conduct foundational malware analysis to identify suspicious behaviour.

    This was the scenario I left to the following day as I ran out of my free time. Not going to lie, throughout dinner and family time it was really hard to switch off and not thinking about finishing this last scenario. I even considered working at night from my laptop, but quickly realised it would be a bit too obsessive.

    Where should I start. The scenario was very interesting, it required to use a few tools for different purposes (sometimes to double-check the information and make sure the previous tool was accurate). There was a mix of tools with GUI and tools you need to run in a terminal, and this variety I enjoyed quite a bit.

    At some point, I did get a bit overwhelmed and had a thought of "I thought I liked it, and I do, but is it a bit too much?" staring at a lot of hex codes, going through strings, but I guess everything is like that at the beginning of a learning journey. I do like the concept of investigation and I'd like to keep practising in this. I hope this is not my urge to replicate a "police detective" role into something more accessible to me right now (its digital version due to my experience and fascination with tech). I guess the more I do this and tasks for other roles, the sooner I will find out.

    I ended up scoring 70/100, and I had to google a lot, I also asked Claude about a tool crashing, turned out it wasn't, I was just running it incorrectly (oops). I also used Claude for some formatting stuff as the questions didn't specify the format of the answer (or not all of them did), and I felt like you could answer in many different ways.

    Conclusion¶

    I think this was a fantastic assessment, I had so much fun doing it. The fact that it was an exam, I paid for it and there was a countdown somewhat spoiled the fun (lol!) as the scenarios were so interactive it felt like a video game (so naturally I'd want to take my time with it). Saying that I was very grateful to be able to try executing tasks across different cybersecurity roles, it ended up feeling like "a day in the life" of those specialists. It's a great time to be alive having all those amazing resources (here, specifically, interactive labs and real tools and artifacts) to be so accessible for us.

    What's next? I'm not sure. The exam definitely gave a taster of specific roles, but I had hoped I'd come out feeling a lot more decisive on what I like and what I don't like, and would be able to choose the next learning path based on that (from here the learning splits into blue team, red team, security engineering, and AI security)... obviously there is also Hack The Box and other things including Over The Wire challenge platform I wanted to go back to. But for now I think I need to give some loving to my Python studies, just for my own career advancement, but also I noticed that now I'm hitting the ceiling of my current Python abilities when I study cybersecurity, and I'd like for this not to happen. Currently, I think when I start a new learning path (which will probably be in the coming days if not today lol), I will choose blue team path... or red?

    Overall, I did feel like an operator and it was the best thing. I totally don't want a "4D 5A" tattoo now, btw.

    EDIT: Been working with Linux both in my personal time and at work recently... now I want 7F 45 4C 46 instead!
